=== Cloud Volumes ONTAP 的遠端資料複寫評估

一項新的評估可用於檢查 Cloud Volumes ONTAP 資料是否受到遠端複寫的保護。它有助於確保您的資料保護計劃符合災難恢復和業務連續性的最佳實務。

link:https://docs.netapp.com/us-en/console-well-architected/cvo/configuration-analysis-cvo.html["了解 Cloud Volumes ONTAP 的組態分析"]



[[dismiss-entire-well-architected-configurations]]
=== 完全關閉架構完善的組態

現在您可以從儀表板中完全忽略某個建議組態。這可讓您更有效地控制哪些建議和評估會顯示在您的環境中。



[[database-workload-recommendations-in-the-well-architected-dashboard]]
=== 架構完善的儀表板中的資料庫工作負載建議

現在，在 NetApp Console 中精心設計的儀表板，已提供使用 FSx for ONTAP 的資料庫工作負載建議。您可以在同一個位置查看儲存資源和資料庫工作負載的狀態，從而全面檢視基礎架構的健全狀況。
