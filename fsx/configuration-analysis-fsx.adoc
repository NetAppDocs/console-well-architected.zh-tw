= Amazon FSx for NetApp ONTAP 組態分析
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Console 中架構完善的儀表板會定期分析儲存系統組態，以確定您的 Amazon FSx for NetApp ONTAP 檔案系統是否存在任何組態問題。發現問題時，儀表板會顯示問題所在，並說明需要進行哪些變更，以確保您的儲存系統達到最佳效能、具成本效益，並符合最佳實務的法規遵循要求。

主要功能包括：

* 每日配置分析
* 對 NetApp ONTAP 儲存系統和合作夥伴儲存設備提供者進行自動最佳實務做法驗證
* 主動可觀測性
* 洞察化為行動


未解析的指令位於 <stdin> - include::well-architected-workloads.adoc[]



[[analysis-requirements]]
== 分析要求

要進行完整的檔案系統分析，必須執行以下操作：

* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["部署 NetApp Console 代理程式"^] 或 link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html["關聯連結"^] 以設定檔案系統與 NetApp Console 之間的連線。
* 在您的 AWS 帳戶中授予 _view、planning 和 analysis_ 權限。
+
link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["了解如何授予 AWS 帳戶權限"^]
