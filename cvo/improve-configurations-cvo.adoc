= 實作架構良好的 Cloud Volumes ONTAP 系統組態
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
利用組態分析洞察和建議，運用 NetApp 為執行在 Microsoft Azure 儲存設備上的 Cloud Volumes ONTAP 系統實作最佳實務做法。您可以輕鬆審查架構良好的狀態、了解組態中存在的問題，並獲得改進建議，以改善任何在可靠性、安全性、效率、效能和成本方面未最佳化的系統架構。

link:configuration-analysis-cvo.html["了解組態分析和架構良好狀態。"]



[[about-this-task]]
== 關於此任務

NetApp 每日分析 Microsoft Azure 中 Cloud Volumes ONTAP 系統的部署。每日分析提供架構完善的狀態、洞察與建議，協助您修正組態問題，使您的系統符合最佳實務。

您無需部署 Console 代理程式即可檢視系統組態問題的建議；但是，Console 代理程式連線可讓 NetApp 對您的系統資源進行最全面的分析。

每日分析完成後，儀表板會顯示架構良好的資源總數、處於關鍵狀態的資源數量以及處於警告狀態的資源數量。組態按架構良好架構的支柱進行分類：可靠性、卓越營運績效、成本優化、效能與效率和安全性。儀表板還包含一個表格，其中列出了所有組態、這些組態的架構良好狀態、嚴重程度、類別、資源類型（Volume 或系統）、受影響的資源，以及在組態未最佳化時檢視建議的選項。



[[before-you-begin]]
== 開始之前

* 您必須link:https://console.netapp.com/add-working-environment/choose-type["新增 Cloud Volumes ONTAP 系統"]至 NetApp Console，才能檢視架構完善的狀態及組態問題的建議。
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["您應該部署 Console 代理程式"]以取得系統資源最全面的分析。




[[view-recommendations-for-configuration-issues]]
== 檢視組態問題的建議

每日分析完成後，您可以檢視針對組態問題的建議。這些建議說明最佳實務做法，以及未最佳化組態的潛在風險。您也可以下載包含這些建議的 CSV 檔案。

.步驟
. 登入 link:https://console.netapp.com/home["NetApp Console"^]。
. 從 NetApp Console 選單中，選取 *工作負載*，然後選取 *架構良好*。
. 從「架構完善的儀表板」中，選取任何組態的 *檢視*。
+
（可選）選取 image:button_download.png["下載圖示的快照"]以下載包含所有組態建議的 CSV 檔案。

. 審查建議。


.接下來
修復組態問題，使系統保持最佳效能運作。
